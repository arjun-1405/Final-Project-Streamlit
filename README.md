# Final Project – Streamlit Application

A Python-based interactive web application built with Streamlit.

## Features

- Interactive Streamlit interface
- Data processing with Pandas and NumPy
- Interactive visualizations using Plotly
- Machine-learning functionality using Scikit-learn
- Browser-based interactive dashboard

## Technologies Used

- Python 3.13
- Streamlit
- Pandas
- NumPy
- Plotly
- Scikit-learn
